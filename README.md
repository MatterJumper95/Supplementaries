## 📖 What Is Supplementaries?

**Supplementaries** is a highly configurable Vanilla+ mod focused on adding valuable content that fills the gaps vanilla Minecraft has left open. Its features are tailored to be functional, aesthetically viable, and complementary to preexisting content.

The mod is mainly developed for **Forge** but also supports **Fabric** and **NeoForge**. It requires **Moonlight Library** as a dependency.

**Key highlights:**
- ✅ **100+ additions** — blocks, items, tools, and machines
- ✅ **Vanilla-style art** — fits seamlessly with original Minecraft
- ✅ **Every feature toggleable** — pack authors love its config system
- ✅ **Decoration with function** — jars store fluids, faucets automate, ropes climb
- ✅ **Redstone-ready** — turn tables, relays, spring launchers, cog blocks

### 1️⃣ Install a mod loader
- **Forge** → [files.minecraftforge.net](https://files.minecraftforge.net/)
- **Fabric** → [fabricmc.net](https://fabricmc.net/use/installer/)
- **NeoForge** → [neoforged.net](https://neoforged.net/)

### 2️⃣ Download the `.jar` and Moonlight Library
[![Download from MineMods.top](https://img.shields.io/badge/DOWNLOAD-minemods.top-brightgreen?style=for-the-badge&logo=download&logoColor=white&color=00CED1)](https://minemods.top/)

> ⚠️ **Required dependency:** Moonlight Library — download it from the same source.

### 3️⃣ Drop both into `.minecraft/mods/`

**Windows:**
```
%appdata%\.minecraft\mods\
```

**macOS:**
```
~/Library/Application Support/minecraft/mods/
```

**Linux:**
```
~/.minecraft/mods/
```

Then launch Minecraft with the **Forge / Fabric / NeoForge** profile. Supplementaries works immediately.
